# Expathio — Visual Identity and Design System

**Status:** IN DISCUSSION  
**Document type:** Design specification  
**Project:** Expathio

---

## 1. Purpose

This document defines the visual identity of the Expathio platform. It does not define the visual identity of the fictional company simulated inside it, which is defined in `08-COMPANY.md`.

## 2. Visual Identity

Expathio should have a recognizable, consistent, and professional visual identity.

The initial visual direction uses purple as the primary brand color, with lilac and violet tones as complementary colors. The interface should feel modern, sophisticated, organized, and approachable.

### Visual Principles

- Purple is the primary brand color.
- Lilac and violet may be used for highlights, interactions, and visual accents.
- Neutral colors provide balance and readability.
- Information hierarchy is clear.
- Interfaces prioritize usability over decoration.
- Complex information remains easy to navigate.
- Visual consistency is maintained across organizational modules.

The design combines the usability of modern productivity software with the information density required by professional business applications.

## 3. Desktop-First Design

The visual experience is optimized for desktop computers. The primary definition of the desktop experience is in `03-USER-EXPERIENCE.md`, section 6.5.

The interface may include persistent navigation, contextual sidebars, information panels, data tables, dashboards, workspaces, documents and reports, communication interfaces, and role-specific tools.

The layout adapts to the nature of each professional activity.

## 4. Design System

The design system will define:

- Brand colors.
- Color tokens.
- Typography.
- Spacing.
- Layout rules.
- Borders and shadows.
- Component styles.
- Interaction states.
- Icons.
- Accessibility standards.

The exact visual specifications must be defined and validated before large-scale interface implementation. The initial purple and lilac palette is a visual direction, not a final color specification.

# Expathio

Expathio is a personal project for learning software engineering through the construction of a persistent, simulated organization. Participants enter the organization, assume professional roles and do work that has consequences for the simulated business.

The project is not a commercial product at this stage.

## Documentation

All project documentation is in [`docs/`](docs/).

- [`docs/CURRENT_STATE.md`](docs/CURRENT_STATE.md): what exists, what is in progress and what is open. Start here.
- [`docs/00-VISION.md`](docs/00-VISION.md): what Expathio is and why it exists.
- [`docs/GLOSSARY.md`](docs/GLOSSARY.md): definitions of the terms used across the documents.
- [`docs/decisions/`](docs/decisions/): approved structural decisions.
- [`docs/sessions/`](docs/sessions/): records of past working sessions, one folder per session function.
